Technical Description

EatCrow2 is a sophisticated SCADA-based autoclave control platform that integrates a C++ and Python serial backend with an interactive web dashboard for telemetry and process automation.

Core Architecture & Features

  • Tri-Mode State Machine: Operates across Manual, Semi-Manual, and Automatic modes, plus a dedicated "Trainer" mode for safe simulation.
  • Macro Engine & Transpiler: Employs a custom Domain-Specific Language (StarForge) to execute automated curing macros via a transpiler engine.
  • Safety & Diagnostics: Governed by heuristic diagnostic algorithms that monitor real-time sensor rates and state errors to isolate hardware faults.
  • Automation Interface: Built as a standalone desktop application featuring hands-free voice control and automated data logging for precision laboratory cycles.

Tech Stack

C++ Python SCADA Arduino Control Theory Flask (Python) JavaScript Machine Learning
