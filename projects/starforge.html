StarForge

StarForge is a custom Domain-Specific Language and macro transpiler engine designed to convert COBOL-inspired scripting commands into JavaScript for automated laboratory curing and hardware control.

Technical Description

StarForge operates as a domain-specific language (DSL) and macro transpiler engine (RAS COBOL) that parses COBOL-inspired syntax strings, validates command parameters against a runtime whitelist, and transpiles high-level macro scripts into an asynchronous JavaScript execution pipeline for automated laboratory hardware control.

Command Set & Keywords Reference

  • CALL / RUN: Invokes specific routines, such as soft macros, hard macros, or board macros.
  • LOG / DISPLAY: Outputs logging text or messages to the console.
  • WAIT: Pauses execution by setting a specified delay time in milliseconds.
  • SET: Configures hardware operational parameters and safety thresholds, such as temperature (TEMP), pressure (PSI), rates (MAX_TEMP_RATE, MIN_TEMP_RATE, MAX_PSI_RATE, MIN_PSI_RATE), and ceilings (TEMP_MAX, PSI_MAX).
  • VAR: Declares a new global variable.
  • CHANGE_VAR: Updates the value of an existing global variable.
  • RUN_JS: Executes sandboxed JavaScript code snippets using |js| delimiters.
  • INPUT / ACCEPT: Prompts the user for input via a dialog box.
  • INPUT_VAR: Prompts the user for input and stores the result in a newly declared variable.
  • REPEAT: Sets a flag to loop the macro execution continuously.
  • STOP: Halts macro execution and triggers a hard stop flag.
  • IF / ELSE: Handles conditional control flow using |cond| structures and relational operators like EQUALS, MORE_THAN, LESS_THAN, IS_NOT, and INCLUDES.
  • MATH_DIVISION / DIVIDE: Enables numerical parsing mode for mathematical division operations.
  • COMMENT: Denotes script commentary or documentation lines.
